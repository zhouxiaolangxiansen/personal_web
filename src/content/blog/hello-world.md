想了很久，还是决定给自己开垦一块自留地。

社交媒体上的内容像流水，发出去就沉底了。而我希望有一个地方，能让想法沉淀下来——像种花一样，慢慢写，慢慢长。

## 为什么是"数字花园"

博客这个词太正式了，我更愿意叫它**花园**：

- 不必按时间倒序才能被看见，文章会随着理解加深而持续修改
- 有草稿、有半成品、也有开得正好的花
- 面向的不是流量，而是自己和偶然路过的同路人

> 花园不需要完美，只需要持续生长。

## 这里会长出什么

1. **写作**：技术笔记、读书感想、偶尔的胡思乱想
2. **摄影**：把镜头里的世界陈列出来
3. **生活**：学习记录、旅行碎片、一些值得纪念的时刻

## 关于这座花园本身

网站用 [Astro](https://astro.build) 搭建，部署在 Cloudflare Pages 上，所有特效都是手写的 CSS 和原生 JavaScript——不依赖任何外部 CDN，因此在网络环境复杂的地方也能稳定加载。

```js
// 这座花园的运行时宣言
while (alive) {
  think();
  write();
  photograph();
}
```

如果你也路过这里，欢迎随便逛逛，留言板以后会有的。
